# Pocket Lock

근접 센서가 가려지면 Android의 시스템 잠금을 요청하는 작은 Android Studio 프로젝트입니다.

## 동작

1. Android Studio에서 이 폴더를 엽니다.
2. 앱을 설치하고 `기기 관리자 권한 허용`을 누릅니다.
3. `주머니 잠금 켜기`를 활성화합니다.
4. 근접 센서가 가려지면 화면이 잠깁니다.

잠금 해제는 Android에 설정한 PIN, 패턴 또는 생체 인증을 사용합니다. 일반 앱은 음량 버튼만으로 시스템 키가드를 해제할 수 없습니다.

## 참고

- 근접 센서가 없는 기기에서는 동작하지 않습니다.
- Android는 포그라운드 서비스 알림을 표시합니다.
- 앱을 삭제하려면 먼저 시스템 설정의 기기 관리자에서 Pocket Lock 권한을 해제해야 합니다.
- 이 프로젝트에는 Gradle wrapper가 포함되어 있지 않으므로 Android Studio가 안내하는 Gradle sync를 사용하세요.
