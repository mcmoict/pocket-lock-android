# Pocket Lock 릴리스 노트

## 1.2.0 (versionCode 32)

- 메인, 사용 방법, 기기 진단 화면의 색상, 버튼, 카드 디자인을 개선했습니다.
- 사용 방법 및 YouTube 안내 버튼에 아이콘을 추가했습니다.

## 1.1.0 (versionCode 31)

- 사용 방법 및 기기 진단 화면을 메인 화면의 보라색 테마에 맞게 개선했습니다.
- 사용 방법을 4단계 안내와 접이식 도움말로 정리하고 불필요한 버튼과 감도 안내를 제거했습니다.
- 메인 화면에서 감도 선택을 숨기고 보통 감도로 동작하도록 조정했습니다.
- 메인 화면 제목과 기기 진단 버튼 글자 크기, 스위치 정렬을 다듬었습니다.

## 1.0.9 (versionCode 30)

- 사용 방법에 휴대폰을 주머니에 넣는 방법을 이미지와 동영상으로 추가했습니다. 이미지를 누르면 확대해서 볼 수 있습니다.
- 사용 방법 텍스트 영역을 모서리 없는 연한 보라색 배경으로 개선했습니다.
